# Slides

Slidev version of the "Understanding and mitigating Prompt Injection" presentation, converted from Google Slides.

```bash
cd slidedev
npm install
npm run dev      # present and edit at http://localhost:3030
npm run build    # static site in dist/
npm run export   # PDF (needs: npm i -D playwright-chromium)
```

Edit `slides.md` to change the content.
